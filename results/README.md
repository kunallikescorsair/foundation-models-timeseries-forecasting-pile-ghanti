# Results

This folder stores final result summaries and visualisations for the benchmark.

## Structure

- `tables/`: final aggregated CSV result tables used for analysis and reporting.
- `figures/`: exported final figures. These can be regenerated from `notebooks/14_final_analysis.ipynb`.

Raw per-series experiment outputs are not included in this repository because they are large and can be regenerated by running the experiment notebooks.
