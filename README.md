## Project Title
Evaluating Foundation Models for Time Series Forecasting on the Time Series PILE

## Project Overview
This capstone project evaluates the effectiveness of foundation models for time series forecasting on the Time Series PILE dataset. The project compares modern pretrained time series foundation models with traditional forecasting baselines across short- and long-horizon forecasting tasks.

## Planned Models

### Foundation Models
- TimesFM
- Tiny Time Mixers (TTM)
- Uni2TS

### Baseline Models
- ARIMA
- Prophet
- LSTM

## Dataset
- Time Series PILE
- Source: Hugging Face dataset by AutonLab

## Evaluation Metrics
- MAE
- RMSE
- MAPE
