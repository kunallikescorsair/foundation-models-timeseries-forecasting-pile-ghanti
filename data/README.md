# Data

Raw Time Series PILE `.tsf` files are not included in this repository due to size and licensing/storage considerations.

Datasets can be downloaded from the Time Series PILE / Monash forecasting collection and placed under:

- `data/raw/`

The final selected datasets are:

- `bitcoin`
- `fred_md`
- `m1_monthly`
- `electricity_weekly`
- `saugeenday`
- `solar_weekly`
- `car_parts`
- `nn5_daily`
- `nn5_weekly`
